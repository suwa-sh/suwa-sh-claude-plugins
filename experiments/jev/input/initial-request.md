# 社内備品貸出システム 初期要望

## 背景

社内のノート PC、プロジェクター、検証用スマートフォンを、総務部が表計算ソフトの台帳で貸し出している。
予約の重複と返却忘れが月に数件起きている。台帳を小さな Web システムに置き換えたい。

## 利用者

- 社員: 備品を借りる人。約 200 名。社内ネットワークからブラウザで使う
- 総務担当: 貸出と返却を記録する人。3 名

## やりたいこと

1. 社員が、備品の空き状況を見て、期間を指定して備品を予約できる
2. 総務担当が、予約に基づいて貸出を記録し、返却されたら返却を記録できる
3. 返却期限を過ぎても返却されていない貸出があれば、借りている社員と総務担当に社内チャットで通知する

## 決まりごと

- 同じ備品の予約期間は重ならない
- 貸出期間は最長 14 日
- 返却期限の超過は 1 日 1 回、朝に確認する

## 外部との連携

- 社内チャットサービス: 通知の送信先。チャットサービスが提供する API を呼び出す
- 社員の認証は、社内の既存のシングルサインオンを使う

## 対象外

- 備品の購入と廃棄の管理
- 貸出の料金計算
- 社外からの利用
