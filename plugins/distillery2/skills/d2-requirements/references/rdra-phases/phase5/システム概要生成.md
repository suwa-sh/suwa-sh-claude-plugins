# Phase5：システム概要.json の作成
- 「初期要望.txt」の内容からシステム名とシステム概要を作成し、JSONとして保存する

## システム名とシステム概要の作成
### システム名
- 「初期要望.txt」の内容から自然な日本語のシステム名を1つ抽出・決定する

### システム概要
- 「初期要望.txt」の内容を要約し、システム概要を生成する
- 具体性を保ちつつ簡潔にまとめる（長すぎない文章量）

### インターフェース種別（interface_kind）
- 「初期要望.txt」から、利用者がシステムに触れる主なインターフェースを判定する
  - `gui`: Web 画面・モバイルアプリなど GUI がある（既定。判断できない場合もこれ）
  - `cli`: コマンドラインのみ（GUI 無し）
  - `api`: API / SDK のみ（GUI 無し）
  - `batch`: バッチ・常駐ジョブのみ（対話インターフェース無し）
- `gui` 以外は「UI 画面を持たないプロダクト」として後段（design-system / spec / pipeline）が design ステージ skip の判断材料にする

## 出力レイアウト（厳守）
- JSONのみ（余計な説明・Markdown・コードフェンスは禁止）
- 形式：{"system_name":"システム名","system_overview":"システム概要","interface_kind":"gui|cli|api|batch"}
- `interface_kind` は省略時 `gui` として扱われる（既存プロジェクト互換）
- ダブルクォートで有効なJSONにする

## ファイルへの出力（厳守）
- 出力先：`1_RDRA/システム概要.json`
- 既存ファイルがあれば上書きする
- 出力ファイルの中身はJSONのみとする
