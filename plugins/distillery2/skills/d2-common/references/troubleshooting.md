# トラブルシューティングの索引 (d2-common)

環境依存の症状と回避策は、踏んだスキルごとの `references/troubleshooting.md` にためる (手順そのものには書かない)。
他スキルの項目へはこの索引から辿る (スキル同士は互いに参照しない。d2-common の「参照の向き」。0.1.31)。

| スキル | 内容 |
|---|---|
| [d2-run](../../d2-run/references/troubleshooting.md) | headless の許可 (変数展開・`cd`・リダイレクト)、`.cjs`、イベント記録のパイプ、`shasum`、runGates の出力の保存先 |
| [d2-foundation](../../d2-foundation/references/troubleshooting.md) | npm 10 の `npm install`、qlty / biome の挙動 |
| [d2-contract](../../d2-contract/references/troubleshooting.md) | redocly、契約の生成器 |
