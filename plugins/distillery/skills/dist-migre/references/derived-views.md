# 派生ビューの変更点

## README-INDEX — 1.13.2

| 観点 | ガイド |
|---|---|
| 判断 | 出力ルートのREADMEにADRやイベントが全件展開されているか |
| 修正 | `generateReadme.js`でREADMEと`_indexes/adrs/{domain}.md`、`_indexes/events/{domain}.md`を再生成する |
| 確認 | domainごとの件数、個別記録へのリンク、最新イベント、既存ADR・イベント本文の保持を確認する |

READMEの手編集による入口リンクがある場合、生成前に退避し、移行後も必要な案内を残す。
indexは派生物。過去イベントやADR本文を索引へ移して削除しない。

## TRACE-MATRIX / TRACE-TYPE / TRACE-SUMMARY-JA — 1.13.3〜1.13.5

| 導入版 | 表の変更 |
|---|---|
| 1.13.3 | 行はRDRA要素、列は全UC。セルには対応箇所のanchorと根拠ファイルへのリンク |
| 1.13.4 | 左端へ種類列を追加。情報の属性・バリエーションの値・条件・状態遷移・外部システム |
| 1.13.5 | 対応付けサマリーの種類も同じ日本語に統一 |

既存の対応記録を`_trace-links.json`と照合し、`buildSpecViews.js`で再生成する。
未対応を空欄のまま維持する。表を埋めるために対応を作らない。
全UCが列に含まれ、同名UCを区別でき、要素の分母がRDRA latestと一致することを確認する。
linkedは根拠への対応記録があることを示し、業務要件の充足や実装完了を保証しない。

実行時は対象版のdist-spec、dist-pipelineのscriptsを使う。中間版への移行では後続版の列を先取りしない。
