### ドメイン設計密度（ヒューリスティクス指標）

> 注: これらは厳密な「網羅率」ではなく、設計が一定の密度・健全性を持つかを判定するヒューリスティクス指標です。RDRA 要素 ID との厳密な照合が可能なのは entity 割当のみ。

| メトリクス | 種別 | 分母 | 分子 | 値 |
|---------|:----:|:------:|:-------:|:-----:|
| BC への entity 割当率 | **coverage**（厳密）| 1 | 1 | 100% |
| Subdomain に BUC 関連付けられている率 | ヒューリスティクス | 1 | 1 | 100% |
| Context Map の存在（BC>=2 なら期待）| ヒューリスティクス | 0 | 0 | -  |
| Core SD 比率（投資集中度）| 設計密度比率 | 1 | 1 | 100% |

凡例:
- **coverage**: 分母の各要素を分子で網羅できているかを表す厳密な指標
- **ヒューリスティクス**: 設計の健全性ヒント。100% でも設計の正しさは保証されない
- **設計密度比率**: 設計判断の比率指標（網羅性ではなく投資配分・分布を表す）

- Subdomain: 1 件 / BC: 1 件 / Context Map: 0 件 / Aggregate 仮説: 1 件
