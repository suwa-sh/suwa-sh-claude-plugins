# adapter: Cursor Agent CLI

- 確認日: 2026-09-05
- 確認バージョン: agent 2026.09.02-c22c1a3 (`cursor-agent` は互換 alias)
- 確認元: 公式 docs (cursor.com/docs/hooks, /docs/cli, /docs/subagents, /docs/skills) を Context7 経由で照合 + ローカル実測 (hook stdin)

## 読込パス

| 面 | パス | 規則 |
|---|---|---|
| Instructions | root の `AGENTS.md`、`CLAUDE.md`、`.cursor/rules/*.mdc` | rules は glob と適用方式を front matter で指定 |
| Skills | `.cursor/skills/<name>/SKILL.md`、`.agents/skills/` | `name` はディレクトリ名と一致する小文字・数字・ハイフン |
| Agents | `.cursor/agents/<name>.md`、`~/.cursor/agents/` | front matter: `name` / `description` / `model` (`inherit` 可) / `readonly: true` |
| Hooks | `.cursor/hooks.json` (project)、`~/.cursor/hooks.json` (user) | project hook は **project root を cwd** に実行。command は project root 基準の相対パス |
| Headless | `agent -p "<prompt>" --output-format text --trust --force` | `--trust` で workspace trust の対話を省略、`--force` (= `--yolo`) で確認なし実行 |

## Hooks

```json
{
  "version": 1,
  "hooks": {
    "beforeShellExecution": [
      { "command": "scripts/agent-hooks/pre-tool-policy.sh  # mid-harness" }
    ]
  }
}
```

- イベント名は Claude 系と違う: `beforeShellExecution` / `afterShellExecution` / `beforeMCPExecution` / `afterFileEdit` / `sessionStart` / `sessionEnd` / `stop` など
- **stdin は `tool_name` を持たない**。実測 (2026-09-05): `{"command": "echo hello-probe", "cwd": "", "hook_event_name": "beforeShellExecution", "workspace_roots": [...], "conversation_id": ..., "sandbox": false, ...}`。`cwd` は空文字だった
- ブロック: **exit 2** (docs: 0 = 続行、2 = ブロック、それ以外は fail-open)。stdout に `{"permission": "deny", "user_message": ..., "agent_message": ...}` を返す形式もある。既定は fail-open。`failClosed: true` を entry に付けると hook 失敗時にブロックできる
- matcher は無い (イベント単位)。shell 以外のツールは `beforeMCPExecution` が別イベント

### 論理イベント → 製品イベント

| 論理 | Cursor |
|---|---|
| `pre-tool` | `beforeShellExecution` (shell のみ。MCP は対象外) |
| `post-tool` | `afterShellExecution` |
| `session-start` | `sessionStart` |
| `stop` | `stop` |

manifest の `matcher` は無視する (Cursor はイベントで絞る)。

### gen_adapters の管理範囲

`.cursor/hooks.json` の `hooks.<event>[]` のうち、`command` が `  # mid-harness` で終わる entry だけを差し替える。`version` が無ければ 1 を書く。

## Skills

`.agents/skills/` を直接読む (docs: "移植性の高い `.agents/skills/`")。生成は不要。

## Agents

`.cursor/agents/<name>.md`:

```md
---
name: reviewer
description: <policy.description>
model: inherit
readonly: true
---
<!-- generated by mid-harness from .agents/agent-specs/reviewer; do not edit -->
<prompt.md 本文>
```

### capability → 設定

| capability | 変換 |
|---|---|
| read | 常に可 |
| edit / shell | どちらも false → `readonly: true` (ファイル編集と状態を変えるシェルを禁止)。片方だけ false は表現できない → unmappable |
| delegate | 個別制御なし → note のみ |
| network | 個別制御なし → note のみ |

## 受け入れテストでの注意

- Opus 系の usage limit に当たると `-p` が `ActionRequiredError` で止まる。verify は `--model auto` を付ける
- `--trust` を付けないと新しい workspace で trust の対話待ちになる
