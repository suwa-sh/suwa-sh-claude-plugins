# ガイドを追加する

実際のplugin.jsonの版とリリース差分から、migration-catalogへ導入版・安定した項目ID・変更点・ガイドを追加する。
前の版の手順を最新仕様で上書きせず、新しい導入版の節として蓄積する。
出力変更のない版も記録し、対象版が未調査か変更なしなのかを区別する。

| ガイドへ含める項目 | 内容 |
|---|---|
| 適用判断 | 現物のどのファイル・schema・状態を読めば分かるか |
| 変更前後 | config・生成物・manifest・done・コードのうち何が変わるか |
| 保持対象 | ユーザー編集、UC ID、規約、コード、テスト、イベント、承認・公開証跡 |
| 依存 | 上流の出力形式と前提。pluginの版が一致することを互換性としない |
| 検証 | 既存validator、生成・型検査・接続テスト、再開可能性の確認 |
| 未解決時 | 影響する範囲、上流への変更案、通常runで再実行するstage |

直前版からと複数版をまたぐ場合、部分適用済みの場合、未完了runがある場合を確認する。
検証した入力と範囲を実施例へ記録し、未実施のcodegen・S0〜S9・アプリ動作を検証済みにしない。
