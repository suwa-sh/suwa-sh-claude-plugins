# 会議室予約システム — RDRA ビュー

社員が Web 画面で、日付と時間帯を指定して会議室ごとの空き状況を確認し、空いている会議室を予約できるシステム。同じ会議室の同じ時間帯への二重予約を防ぎ (同時に予約されても成立は 1 件だけ)、予約した本人は開始時刻より前であれば自分の予約を取り消せる。取り消した予約は空き状況と重なりの判定から外れる。共有の表計算ファイルで起きていた二重予約や取り消しの未反映を解消する
