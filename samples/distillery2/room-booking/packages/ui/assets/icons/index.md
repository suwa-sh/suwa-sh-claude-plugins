# アイコン一覧

24x24 の線のアイコン。色は文字色 (currentColor) に従う。部品からは `components/ui/Icon.tsx` の `<Icon name="..." />` で使う (同じ形をインラインで描く)。

| name | 用途 | 導いた元 (RDRA) |
|---|---|---|
| search | 空き状況を調べる・ナビの「空き状況」 | 空き状況画面 / UC「会議室の空き状況を照会する」 |
| calendar | 日付・ナビの「自分の予約」・予約が無いとき | 情報「予約」の日付 / 自分の予約一覧画面 |
| clock | 時間帯 (開始時刻・終了時刻) | 情報「予約」の開始時刻・終了時刻 |
| user | ログイン中の社員 | アクター「社員」 |
| door | 会議室・ロゴ | 情報「会議室」 |
| check-circle | 空き・完了 | バリエーション「空き状況」の「空き」 |
| x-circle | 予約済み・取り消し・業務のエラー | バリエーション「空き状況」の「予約済み」 / UC「予約を取り消す」 |
| alert-circle | 注意・お知らせ | 条件「予約時刻の妥当性」「予約の取消可否」で受け付けないときの表示 |
