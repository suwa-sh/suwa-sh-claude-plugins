# デザインの要約 (確認用)

図書館蔵書管理システムの画面の見た目と部品をまとめた。
利用者向けと司書向けの 2 系統の画面を、1 つのアプリの中で出し分ける。

## 1. 確認してほしいこと

| # | 確認事項 | いまの仮置き | 判断材料 |
|---|---|---|---|
| 1 | ブランドの色 | 主色 紺 #1F4E79 / 副色 深緑 #2F6F5E / 強調色 琥珀 #B45309 / 中立色 灰 #5B6470 | ブランド資料が無いため、システムの性格から推論した値。確信度は低い |
| 2 | 書体 | Noto Sans JP (見出し・本文とも) | Web フォントとしては読み込んでいない。未導入の端末では OS の日本語書体で表示する |
| 3 | 司書向け画面の色 | 灰 (中立色の濃い色) | 利用者向け (紺) と一目で区別できるようにした |
| 4 | 利用者の一覧画面が無い | 編集・退会の画面で「利用者番号で呼び出す」欄を置いた | 要求に利用者の一覧・検索画面が無いため、画面を増やさなかった。司書が利用者番号を知らない場面があるなら、一覧画面の追加を要求側に戻す |
| 5 | 利用者の予約の入口 | 検索結果の「予約する」ボタンから予約画面へ進む | 貸出中・予約待ちの本にだけボタンを出す。在庫ありの本は「館内で借りられます」と表示する |

- ブランドの由来: **推論 (低確信)**。ブランドガイドラインが無いため、設計判断の記録に仮置きされた値をそのまま使った。
- 色と書体を変える場合は、トークン (`src/tokens/tokens.json` と `src/styles/design-tokens.css`) を作り直す。

## 2. 画面の一覧 (19 画面)

メール通知 3 件 (受取可能・返却期限のお知らせ・延滞の督促) は自動送信で、画面を持たない。

### 利用者向け (紺)

| 画面 | 何をする画面か | 状態のバリエーション |
|---|---|---|
| 利用者ログイン | 図書館の認証画面へ移動してログインする | 通常 / 失敗 |
| 書籍を探す | 項目 (キーワード・タイトル・著者・ISBN・ジャンル) を選んで検索し、在庫状況を見る | 結果あり / 該当なし / 失敗 / 読み込み中 |
| 書籍を予約する | 貸出中の本の予約を確定し、予約順位を知る | 確認 / 予約できない / 読み込み中 / 完了 |
| 予約を取り消す | 待機中の自分の予約を取り消す | 確認 / 取り消せない / 完了 |
| 借りている本 | いま借りている本の返却期限と延滞、過去に借りた本を見る | 一覧 / なし / 失敗 / 読み込み中 |
| 予約している本 | 予約の順位と受取可能かどうかを見る | 一覧 / なし / 失敗 / 読み込み中 |

### 司書向け (灰)

| 画面 | 何をする画面か | 状態のバリエーション |
|---|---|---|
| 司書ログイン | 図書館の認証画面へ移動してログインする。司書でない人は拒否する | 通常 / 権限なし |
| 所在確認 | 問い合わせの本を探して在庫状況を案内する。編集・除籍へ進む | 結果あり / 該当なし / 失敗 / 読み込み中 |
| 書籍受入 | 受け入れた本を登録する。タイトルは必須、媒体の既定は紙 | 入力 / 入力エラー / 完了 |
| 書籍情報の編集 | 出版社・ジャンルなどを直す | 入力 / 入力エラー / 読み込み中 / 完了 |
| 書籍の除籍 | 本を蔵書から外す。貸出中・取り置き中・予約ありは外せない | 確認 / 除籍できない / 完了 |
| 利用者受付 | 利用者を登録する。利用者番号は自動で割り当てる | 入力 / 入力エラー / 完了 |
| 利用者情報の編集 | 連絡先などを直す。以後のお知らせは新しい連絡先へ送る | 入力 / 入力エラー / 完了 |
| 利用者の退会 | 利用者を退会させる。借りている本がある人は退会できない | 確認 / 退会できない / 完了 |
| 貸出受付 | 利用者番号と本の番号で貸し出す。返却期限は自動で決まる | 入力 / 貸し出せない / 完了 |
| 返却受付 | 返却を登録する。予約があれば取り置きにしてお知らせを送る | 入力 / 返却できない / 完了 / 完了 (取り置きあり) |
| 在庫状況レポート | 在庫あり・貸出中・予約待ちの数と本ごとの内訳を見る | 一覧 / なし / 失敗 / 読み込み中 |
| 人気書籍ランキング | 期間を決めて、よく借りられた本の順位を見る | 一覧 / なし / 失敗 / 読み込み中 |
| 貸出統計 | 日・月・年の単位で貸出件数の推移を棒グラフで見る | グラフ / なし / 失敗 / 読み込み中 |

## 3. 部品の一覧

## 4. 見た目の決まり

| 項目 | 内容 |
|---|---|
| 主要色 | 利用者向けは紺、司書向けは灰。画面の外枠に属性を付けて切り替える |
| 状態の色 | 在庫あり・完了は緑、貸出中・待機中は青、予約待ち・受取可能・期限間近は琥珀、延滞・エラーは赤 |
| 色だけに頼らない | 延滞・期限間近は色に加えてアイコンと文言で伝える |
| 文字 | Noto Sans JP。本文の行の高さは 1.7 |
| 余白 | 4px 刻み。画面の外周 1.5rem、区切りの間 2rem、部品の間 0.75rem、カード内 1.5rem |
| 配置 | 12 列の格子。入力画面は中央寄せ、一覧とレポートは全幅 |
| 左メニューの幅 | 16rem (司書のメニュー 9 項目から) |
| 画面幅への対応 | スマートフォン・タブレット・PC の 3 段階。狭い画面では左メニューを上部の横並びに変える |
| ダークモード | すべての色に暗い背景用の値を用意した |
| 読みやすさ | 文字と背景の明暗差を主要 20 組で確認し、すべて基準 (4.5 倍以上) を満たした。キーボード操作時は枠を強調表示する |

## 5. 画面の確認状況

- 部品と画面の Storybook は組み立てに成功した。
- 全 164 状態を撮影した (`docs/design/screenshots/`)。
- 撮影した画像でのはみ出し・文字切れ・明暗差を確認した。PC 幅・スマートフォン幅・ダークモードで主な画面を見た。
- 確認で直したこと: 狭い画面で表の書名が 1 文字ずつ折り返す問題、ダークモードの削除ボタンの明暗差不足。
- 補足: 標準の撮影手順はファイルを直接開くため白紙になった。そのため、同じ画像名で配信経由の撮影をやり直した。

## 6. 自動で選んだこと (確信度が低いもの)

| 選んだこと | 理由 |
|---|---|
| ブランドの色 4 色と書体 | 設計判断の記録に仮置きされた値。人の確認待ち |
| 司書向けの色を灰にした | 2 系統の画面の既定の組み合わせ (青系 + 灰系) に合わせた |
| 貸出期間の案内を 14 日で表示 | 貸出期間は設定値で、実際の値は画面側で差し替える |
| 返却期限の「間近」を残り 2 日以下とした | 注意表示の目安。お知らせを送る日数の設定とは別 |
| 予約の取り消しで「受取可能」になった予約は取り消せない表示にした | 要求は「待機中だけ取り消せる」と定めているため |
