## 事実

- `docs/rules/tier-backend.md`: 「OpenAPI の provider なら、入出力型・ルーティングは `packages/contracts` の生成物起点」
- `packages/contracts/api/` には `stubs/createLoan.*.json` (消費側の stub) だけがあり、TypeScript の型 (CreateLoanRequest / Loan / Problem) が生成されていない
- `packages/contracts/` には package.json が無い。`db/tables.ts` は相対パス (`../../../../../packages/contracts/db/tables`) で import している
