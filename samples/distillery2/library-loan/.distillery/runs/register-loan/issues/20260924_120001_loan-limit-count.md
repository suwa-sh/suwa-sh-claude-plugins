# 利用者区分ごとの貸出上限冊数の値が要求に無い

## 事実

- `条件.tsv` 貸出可否条件: 「利用者区分ごとの貸出上限冊数を超えない場合に貸出できる」
- `バリエーション.tsv` 利用者区分: 一般、児童、学生 (「貸出上限冊数を変える貸出可否条件」に使うと説明)
- 一般・児童・学生それぞれの上限冊数の値が、要求・RDRA・ADR のどこにも無い
- `requirements.yaml` の SPEC-002-01 の受入基準にも上限冊数に関する項目は無い

## シナリオへの影響

- 上限ちょうど (貸出できる) と上限超過 (貸出できない) の境界値シナリオを書けない
- `features/貸出業務/register-loan.feature` に `# TODO(issue: ...)` を残し、シナリオは書いていない

## 確認したいこと

- 利用者区分ごとの貸出上限冊数 (一般・児童・学生)
- 上限の数え方 (貸出状態が貸出中と延滞の貸出を数えるか)
