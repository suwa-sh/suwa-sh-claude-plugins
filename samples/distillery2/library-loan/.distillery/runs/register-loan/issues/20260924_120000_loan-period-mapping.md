# 貸出期間 (7日・14日・21日) の適用規則が要求に無い

## 事実

- `条件.tsv` 返却期限算出条件: 「返却期限は貸出日に利用者区分と媒体種別に応じた貸出期間（7日・14日・21日）を加算して算出する」
- `バリエーション.tsv` 利用者区分: 一般、児童、学生。媒体種別: 紙、電子
- どの利用者区分 × 媒体種別の組み合わせに、どの貸出期間を適用するかの対応表が、要求・RDRA・ADR のどこにも無い

## シナリオへの影響

- `features/貸出業務/register-loan.feature` の返却期限シナリオは、「返却期限 = 貸出日 + 適用された貸出期間」と「貸出期間は 7・14・21 日のいずれか」だけを確かめている
- 利用者区分ごとの具体的な返却期限 (例: 一般・紙 → 14 日後) は書けない。`# TODO(issue: ...)` を残した

## 確認したいこと

- 利用者区分 (一般・児童・学生) × 媒体種別 (紙・電子) ごとの貸出期間の対応表
- 対応表が決まれば、区分ごとの返却期限をシナリオアウトラインで追加する
