## 事実

- 生成物 `apps/backend-api/test/contract/createLoan.test.ts` と `db-schema.test.ts` (d2-contract / genContractTests) が、
  ルート `biome.json` (quoteStyle single, lineWidth 100) の `biome format` で差分ありと判定される。
- ティアの `format_check` (`npm run format:check -w apps/backend-api` = `biome format .`) は、実装前の時点で exit 1 だった。
- 生成物は手で直せない (common.md 必須 1、tier-impl.md 禁止事項)。
- `db-schema.test.ts:687` の非 null アサーション (`!`) は lint の warning (exit には影響しない)。

## 暫定対応 (backend-api の write-set 内)

- `apps/backend-api/biome.json` (nested config、`extends: "//"`) で、formatter の対象から `test/contract/**` だけを外した。
  lint と typecheck、ルートからの `biome format apps/backend-api` は引き続き対象。

## 求める対応

- genContractTests の出力を biome の設定 (single quote、行幅 100) で整形して生成する。
  または、foundation の biome 設定で生成テストのディレクトリを formatter の対象外にする。
- 対応後は `apps/backend-api/biome.json` を削除してよい。
- frontend / worker の契約テストでも同じ問題が起きる可能性がある。
