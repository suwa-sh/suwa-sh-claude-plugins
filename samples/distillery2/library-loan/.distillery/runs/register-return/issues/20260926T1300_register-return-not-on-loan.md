## 事実

- SPEC-003-02 の受入基準は、貸出中の書籍 (予約なし / 予約あり) を返却する 2 件だけを持つ。
- `条件.tsv` に返却の可否を定める条件が無い。`状態.tsv` の「返却を登録する」の遷移元は、書籍状態が貸出中、貸出状態が貸出中または延滞だけである。
- 在庫ありまたは予約待ちの書籍 (未返却の貸出が無い書籍) を司書が返却しようとした場合の結果 (拒否するか、何を表示するか) は要求に記述が無い。
- 返却受付画面 (ReturnRegister) には Error の variant があるが、どの業務条件で出すかは要求から読めない。

## 選択肢

| 案 | 内容 |
|---|---|
| ⭐推奨 A | 未返却の貸出が無い書籍の返却は受け付けない。返却できない旨を表示し、貸出と書籍の状態は変えない |
| B | 何もせず成功として扱う (冪等に返却済として応答する) |
| C | 要求に書かれるまでシナリオを書かない (現状) |

## 決定

- 案 A を採用した (オーケストレータ判断、2026-09-26)。
- 未返却の貸出が無い書籍の返却は受け付けない。返却できない旨を表示し、貸出と書籍の状態は変えない。
- 要求は変えない。SPEC-003-02 に受入基準は追加しない。

## シナリオ側の扱い

- `features/貸出業務/register-return.feature` にシナリオ「未返却の貸出が無い書籍は返却を登録できない」を追加した (受入タグなし)。
