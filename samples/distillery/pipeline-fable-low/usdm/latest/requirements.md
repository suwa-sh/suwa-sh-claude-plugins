# USDM 要求仕様書

- システム名: 図書館蔵書管理システム
- イベントID: 20260903_030744_initial_build
- 作成日時: 2026-09-03T03:07:44
- ソース: input/初期要望.txt

| ID | 要求 | 仕様 | 理由（背景） | 説明 |
|----|------|------|------------|------|
| REQ-001 | 図書館の蔵書と利用者の情報を一元管理できるようにする | | 蔵書と利用者の情報が紙台帳と表計算ファイルに分散しており、管理の手間とミスが発生しているため | |
| SPEC-001-01 | | 司書が書籍情報（タイトル、著者、ISBN、出版社、ジャンル等）を登録・編集・削除できる | | 1. Given 司書がログイン済み When 書籍情報を入力して登録する Then 書籍が蔵書として登録され一覧に表示される<br>2. Given 登録済みの書籍がある When 司書が書籍情報を編集して保存する Then 変更内容が反映される<br>3. Given 登録済みの書籍がある When 司書が書籍を削除する Then 書籍が蔵書一覧から除外される |
| SPEC-001-02 | | 司書が利用者情報（氏名、連絡先、利用者番号等）を登録・編集・削除できる | | 1. Given 司書がログイン済み When 利用者情報を入力して登録する Then 利用者番号が付与され利用者が登録される<br>2. Given 登録済みの利用者がいる When 司書が利用者情報を編集して保存する Then 変更内容が反映される<br>3. Given 登録済みの利用者がいる When 司書が利用者を削除する Then 利用者が利用者一覧から除外される |
| SPEC-001-03 | | 書籍をキーワード、タイトル、著者、ISBN、ジャンルで検索できる | | 1. Given 書籍が登録済み When タイトルの一部をキーワードとして検索する Then 該当する書籍の一覧が表示される<br>2. Given 書籍が登録済み When 著者・ISBN・ジャンルのいずれかを条件に検索する Then 条件に一致する書籍の一覧が表示される<br>3. Given 検索結果がある When 一覧の書籍を選ぶ Then 書籍の詳細と在庫状況が表示される |
| REQ-002 | 書籍の貸出・返却・予約を Web 画面から行えるようにする | | 貸出・返却・予約の管理を司書が手作業で行っており、手間とミスの原因になっているため | |
| SPEC-002-01 | | 司書が利用者と書籍を指定して貸出を記録し、書籍の状態を貸出中にする | | 1. Given 在庫ありの書籍と登録済み利用者がいる When 司書が貸出を登録する Then 貸出記録が作成され書籍の状態が貸出中になる<br>2. Given 書籍が貸出中 When 別の利用者に貸出を登録しようとする Then 貸出できない旨が表示される |
| SPEC-002-02 | | 司書が返却を記録し、書籍の状態を在庫ありに戻す | | 1. Given 書籍が貸出中 When 司書が返却を登録する Then 貸出記録が返却済みになり書籍の状態が在庫あり（予約があれば予約待ち）になる |
| SPEC-002-03 | | 利用者が貸出中の書籍に予約でき、予約は受付順に管理される | | 1. Given 書籍が貸出中 When 利用者が予約する Then 予約が受付順の順位つきで登録される<br>2. Given 書籍が在庫あり When 利用者が予約しようとする Then 予約できない旨が表示される<br>3. Given 予約がある When 利用者が予約を取り消す Then 予約が取消され後続の順位が繰り上がる |
| SPEC-002-04 | | 書籍が返却されたら予約順 1 位の利用者にメールで通知する | | 1. Given 予約が 1 件以上ある書籍 When 返却が登録される Then 予約順 1 位の利用者に返却通知メールが送信される |
| REQ-003 | 貸出期限の管理と延滞者への通知を自動化する | | 期限管理と督促を司書が手作業で行っており、漏れやミスが発生しているため | |
| SPEC-003-01 | | 貸出時に返却期限を自動設定する | | 1. Given 貸出期間が設定されている When 貸出を登録する Then 貸出日に貸出期間を加算した返却期限が自動設定される |
| SPEC-003-02 | | 返却期限が近づいた貸出に対してリマインドメールを自動送信する | | 1. Given 返却期限まで所定日数以内の貸出がある When 日次バッチが実行される Then 該当利用者にリマインドメールが送信される |
| SPEC-003-03 | | 返却期限を超過した貸出に対して督促メールを自動送信する | | 1. Given 返却期限を過ぎて未返却の貸出がある When 日次バッチが実行される Then 該当利用者に督促メールが送信され貸出が延滞状態になる |
| REQ-004 | 利用者が自分の貸出履歴と予約状況を Web 画面で確認できるようにする | | 利用者が自分の状況を司書に問い合わせなくても把握できるようにし、利用者サービスを向上させるため | |
| SPEC-004-01 | | 利用者が自分の過去および現在の貸出履歴を一覧で確認できる | | 1. Given 利用者がログイン済み When 貸出履歴画面を開く Then 自分の現在の貸出（返却期限つき）と過去の貸出が一覧表示される |
| SPEC-004-02 | | 利用者が自分の予約状況（予約順位、状態）を確認できる | | 1. Given 利用者に予約がある When 予約状況画面を開く Then 予約中の書籍と予約順位が一覧表示される |
| REQ-005 | 司書が在庫状況・人気書籍ランキング・期間別貸出統計をレポートとして把握できるようにする | | 蔵書運用の状況を定量的に把握し、選書や運営改善に活かすため | |
| SPEC-005-01 | | 司書が書籍ごとの在庫状況（貸出中・在庫あり・予約待ち）を一覧で確認できる | | 1. Given 書籍が登録済み When 司書が在庫状況一覧を開く Then 各書籍の状態（貸出中・在庫あり・予約待ち）が表示される |
| SPEC-005-02 | | 司書が貸出回数に基づく人気書籍ランキングを確認できる | | 1. Given 貸出記録がある When 司書がランキング画面を開く Then 貸出回数の多い順に書籍が表示される |
| SPEC-005-03 | | 司書が期間（日・月・年）を指定して貸出統計を確認できる | | 1. Given 貸出記録がある When 司書が期間を指定して統計を表示する Then 期間内の貸出件数が集計されて表示される |
| REQ-006 | 将来的に電子書籍にも対応できるようにしておく | | 紙の書籍に加えて電子書籍の提供が想定されるため、拡張しやすい構造にしておきたい | |
| SPEC-006-01 | | 書籍に媒体種別（紙・電子）を持たせ、将来の電子書籍対応時に既存機能を拡張できるようにする | | 1. Given 書籍を登録する When 媒体種別を指定する Then 書籍に媒体種別が保持される（初期リリースでは紙のみ運用） |
