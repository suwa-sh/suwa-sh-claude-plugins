# データ可視化設計仕様

対象: 図書館蔵書管理システム（brand: Libro）
入力: RDRA（情報「貸出統計」「通知」「書籍」、バリエーション「集計期間種別」「ジャンル」、状態モデル）、design digest（StatCard / PeriodStatChart / RankingList / PeriodSelector / ToggleGroup / OverdueTable / tokens.chart）
可視化の利用者は司書のみ（運営分析業務・期限管理業務）。利用者ポータルにチャートは置かない。

## 可視化対象

| 画面 | 指標/データ | 用途 | チャート種別 |
|------|-----------|------|-----------|
| 在庫状況一覧画面 | 書籍の状態別件数（在庫あり / 貸出中 / 予約待ち） | Composition（構成比） | StatCard 3 枚（件数のみ。InventorySummary の available / onLoan / reserved）+ ToggleGroup で状態別絞り込み → BookTable（inventory）。円グラフは使わない（3 項目は数値で足りる） |
| 在庫状況一覧画面 | ジャンル別の状態別件数 | Comparison（比較） | 積み上げ棒グラフ（横）: ジャンル 8 行 × 状態 3 系列。初期リリースは BookTable のジャンル絞り込みで代替可（任意） |
| 人気書籍ランキング画面 | 書籍別貸出回数 上位 N（既定 20）と期間内総貸出回数 | Comparison（比較・順位） | RankingList（順位 / 書籍 / ジャンル / 貸出回数バー）。バーは横棒で最大値を 100% とする |
| 人気書籍ランキング画面 | 期間内貸出件数 / 上位 1 位の貸出回数 | Comparison（サマリー） | StatCard 2 枚（PopularBooksResponse に前期値が無いため delta は出さない） |
| 期間別貸出統計画面 | 集計期間種別（日 / 月 / 年）ごとの貸出件数推移 | Trend（傾向） | PeriodStatChart（縦棒グラフ、1 系列）。離散期間の件数のため折れ線ではなく棒を用いる（LoanStatisticsPoint に系列単位の前期値が無いため前期の並置はしない） |
| 期間別貸出統計画面 | 期間内貸出件数（delta = 前期比）/ 1 期間あたり平均 | Trend（サマリー） | StatCard 2 枚。前期比は LoanStatisticsResponse.previousTotalLoans から算出する |
| 延滞・督促状況画面 | 延滞件数 / 督促失敗件数 / 督促待ち件数 | Comparison（現状把握） | StatCard 3 枚（OverdueSummary の overdueCount / noticeFailedCount / noticePendingCount。destructive / warning のアイコン） |
| 延滞・督促状況画面 | 延滞中の貸出明細と最終督促日時・送信結果 | 一覧（ドリルダウン） | OverdueTable + DueDateIndicator（overdue）+ NotificationLogTable（折りたたみ） |

データ源:
- 在庫状況 / 延滞・督促: 書籍・貸出・通知の現在値（リアルタイム）
- 人気書籍ランキング / 期間別貸出統計: 情報「貸出統計」（集計テーブル、集計日時を画面に表示）

## チャート選定ガイドライン

以下の観点別チャート選定に従う。

### 観点別チャート選定

| 観点 | 推奨チャート | 使用場面 |
|------|-----------|---------|
| Comparison（比較） | 横棒グラフ（RankingList のバー）、StatCard の並置 | 人気書籍ランキング（書籍間の貸出回数比較）、延滞・督促状況（延滞 / 督促失敗 / 督促待ちの件数比較） |
| Composition（構成比） | StatCard の件数、積み上げ横棒（ジャンル別・任意） | 在庫状況一覧（書籍の状態 3 区分）。項目数 3 のため円グラフより数値カードを優先する |
| Relationship（関連性） | 採用しない | RDRA に相関分析の UC が無い |
| Distribution（分布） | 採用しない | 貸出期間は固定値のため分布分析の対象が無い。将来の延滞日数分布はヒストグラム候補 |
| Trend（傾向） | 縦棒グラフ（PeriodStatChart。単系列） | 期間別貸出統計（日 / 月 / 年の貸出件数推移） |

### データ表現フレームワークの適用

| 表現方法 | 適用箇所 |
|---------|---------|
| % Change（変化率） | StatCard.delta: 期間別貸出統計の前期比（LoanStatisticsResponse.previousTotalLoans。例: 前月比 +12%）。人気書籍ランキング・在庫状況一覧は API に前期値が無いため delta を出さない |
| Variance（差異） | 在庫状況一覧: 貸出中 + 予約待ちの比率を「稼働率」として提示する（InventorySummary に前回集計値が無いため delta は出さない） |
| Calculated Metric（計算指標） | 期間別貸出統計: 1 期間あたり平均貸出件数。人気書籍ランキング: 書籍あたり貸出回数 |
| Added Context（追加コンテキスト） | RankingList: ジャンルを併記して選書判断につなげる |

### 集計期間種別と表示粒度

| 集計期間種別 | 既定範囲 | バー本数の目安 | X 軸ラベル |
|------------|---------|-------------|-----------|
| 日 | 直近 30 日 | 30〜31 | MM/DD（sm では 5 日おき） |
| 月 | 直近 12 か月 | 12 | YYYY/MM |
| 年 | 直近 5 年 | 5 | YYYY |

日付表記は YYYY/MM/DD 固定（arch CTP-007）。PeriodSelector は人気書籍ランキング画面と期間別貸出統計画面で共通で、画面間で期間をクエリ引き継ぎする。

## ダッシュボード設計原則

本システムに独立したダッシュボード画面は無い（RDRA に該当 UC が無いため追加しない）。分析レポート 3 画面と延滞・督促状況画面をそれぞれ「サマリー → 明細」の 2 層で構成する。

### 情報の階層化

- **全体サマリー**: 各画面の上部に StatCard を 2〜3 枚（最大 4 枚）並べる。値は value_size（3xl）、ラベルは label_color、前期比は delta
  - 在庫状況一覧: 在庫あり / 貸出中 / 予約待ち（3 枚）
  - 人気書籍ランキング: 期間内貸出件数 / 1 位の貸出回数（2 枚）
  - 期間別貸出統計: 期間内貸出件数（delta = 前期比）/ 1 期間あたり平均（2 枚）
  - 延滞・督促状況: 延滞件数 / 督促失敗 / 督促待ち（3 枚）
- **ドリルダウン**: StatCard または ToggleGroup の選択で下部の明細を絞り込む。明細行から対象画面へ遷移する
  - 在庫状況一覧 → BookTable（inventory）の行 → 書籍別予約状況画面（予約待ちの場合）
  - 人気書籍ランキング → RankingList の行 → 蔵書一覧画面（該当書籍で絞り込み）
  - 期間別貸出統計 → PeriodStatChart のバー → 集計期間種別を 1 段細かくして再表示（年 → 月 → 日）（将来拡張。初期リリースは PeriodSelector での粒度変更のみ）
  - 延滞・督促状況 → OverdueTable の行 → 窓口利用状況照会画面（利用者番号を引き継ぐ）
- **フィルター**:
  - 在庫状況一覧: 書籍の状態（ToggleGroup single）、ジャンル（Select）
  - 人気書籍ランキング: 期間（PeriodSelector）、上位 N（10 / 20 / 50）
  - 期間別貸出統計: 集計期間種別と範囲（PeriodSelector）
  - 延滞・督促状況: 利用者番号（Input with-icon）、並び順（返却期限 / 延滞日数 / 最終督促日時）

### データストーリーテリング

- **ナラティブ**:
  - 在庫状況一覧: 「蔵書のうちどれだけが動いているか」（稼働率）と「予約待ちで需要超過の書籍はどれか」
  - 人気書籍ランキング: 「この期間にどの書籍・ジャンルが求められたか」→ 選書・複本購入の根拠
  - 期間別貸出統計: 「貸出は増えているか、季節性はあるか」→ 運営改善（開館時間・企画展示）の根拠
  - 延滞・督促状況: 「今日対応すべき延滞はどれか」「督促が届いていない利用者はいるか」
- **比較軸**: 前期比（前日 / 前月 / 前年の同期間）は API が前期値を返す期間別貸出統計でのみ提示する。目標比・他館比は RDRA に指標が無いため設けない
- **アクション**:
  - 予約待ち書籍が多い → 書籍別予約状況画面で待ち人数を確認し、複本購入を検討する
  - 上位ランキングにジャンル偏り → 選書の見直し
  - 貸出件数の減少傾向 → 運営改善の検討
  - 督促送信失敗 → 窓口利用状況照会画面で連絡先を確認し、利用者情報を修正する

### 待ち時間と鮮度の表示（NFR B.2.1.3）

- 集計中は Skeleton（card / line）+ 「集計中」文言を表示する（design nfr_decisions）
- 集計テーブル由来の画面は「集計日時: YYYY/MM/DD HH:mm」を StatCard 群の右上に表示する
- PeriodSelector 変更ごとに再集計し、10 秒を超える場合は Alert（warning）で範囲の縮小を促す

## 認知負荷への配慮

- ワーキングメモリの限界（4-5 項目）を考慮した情報量設計
  - 1 画面の StatCard は 3 枚を基本、最大 4 枚
  - チャートは 1 画面 1 つ。系列は 1 系列 + 比較用の 1 系列（bar_muted）まで
  - RankingList の既定は上位 20 件、Pagination は使わず上位 N の切替で制御する
- Data-Ink Ratio を意識した装飾の排除
  - PeriodStatChart はグリッド線を chart.grid（border 色）の水平線のみ、背景・枠線・影・3D・グラデーションなし
  - バー色は chart.bar（primary）1 色。強調が必要な最大値のみラベルを太字にする
  - 数値ラベルはホバー / フォーカス時と最大値・最新値のみ表示する
  - RankingList のバーは背景色なし、長さのみで表現する
- ゲシュタルトの法則に基づくグルーピング
  - 近接: StatCard を component_gap で密に並べ、明細との間は section_gap で離す
  - 類同: 状態の色（success / info / pending / destructive）を StatCard のアイコン、バッジ、ToggleGroup の選択状態で一致させる
  - 閉合: サマリー群と明細はそれぞれ Card（default）で囲む
  - 連続: 期間別の棒は等間隔に並べ、欠損期間は 0 本のバー（ラベルは表示）で連続性を保つ
- 色に依存しない表現（JIS X 8341-3 AA）
  - すべてのチャートに数値ラベルまたは同内容のテーブル（Table）を併置する。PeriodStatChart はスクリーンリーダー向けに同一データの表を視覚的に隠して提供する
  - StatCard の delta は「+12%」の符号と上下矢印アイコンを併記する
  - 単系列を基本とするため色覚多様性への依存が生じない。2 系列の場合は primary と bar_muted（明度差）で区別する
- ドハティの閾値: 0.4 秒を超える取得は即時 Skeleton を出す
