## 8. Dark Mode の適用

- `.dark` クラスと `@media (prefers-color-scheme: dark)`（`.light` 未指定時）の両方で override を定義
- status 系の `-light` は `-50` 色ではなく `rgba()` 半透明値を使う（暗背景で明るすぎるため）
- `--hover-muted` は light gray-200 / dark gray-700
- すべての semantic / component トークンに dark 値がある（card / table / sidebar / modal / pii / chart）
