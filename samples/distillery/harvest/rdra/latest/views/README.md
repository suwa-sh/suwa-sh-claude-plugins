# 図書館システム — RDRA ビュー

公立図書館の司書業務（カウンター業務）を支援するシステム。中核業務は資料の貸出・返却と予約・取置の管理である。貸出では会員種別（中学生以上/小学生以下）ごとの貸出点数制限（20点/15点、うち視聴覚資料5点）や延滞状況（15日以上で新規貸出不可、2ヶ月以上で貸出停止）に基づく貸出可否判定を行い、会員の有効性・所蔵品の在庫状態・二重貸出を検証したうえで貸出を登録する。返却では所蔵品を在庫中に戻すとともに、個人情報保護のため会員と貸出記録の紐付けを削除する。予約では会員がキーワードで所蔵品目を検索し、在庫の有無を問わず貸出予約を登録できる。司書は未準備の予約から在庫数と待ち順番に基づき取置を準備し、会員への通知、取置期限（取置日+7日）の管理、受け渡し（貸出）、期限切れ処理、在庫がない場合の予約取消までの一連の状態遷移（未準備→準備完了→解放/期限切れ/取消）を扱う。また、図書館館長の督促業務を支援する貸出期限切れ確認機能（REST API）を部分的に備える。
