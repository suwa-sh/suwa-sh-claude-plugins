# デザイントークン

図書館蔵書管理システム (Libra) のデザイントークン一覧です。
定義の正本は `src/styles/design-tokens.css` です。このページはその内容を可視化したものです。

---

## 1. 概要

### 3 層構造

トークンは primitive → semantic → component の 3 層で構成します。

<table>
  <thead>
    <tr>
      <th>層</th>
      <th>役割</th>
      <th>例</th>
      <th>直接使ってよいか</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>primitive</td>
      <td>生の値。用途を持たない</td>
      <td><code>var(--color-blue-700)</code> <code>var(--spacing-4)</code></td>
      <td>色は不可 / 寸法は可</td>
    </tr>
    <tr>
      <td>semantic</td>
      <td>用途レイヤー。primitive を参照する</td>
      <td><code>var(--foreground)</code> <code>var(--destructive)</code></td>
      <td>可（推奨）</td>
    </tr>
    <tr>
      <td>component</td>
      <td>コンポーネント固有。semantic を参照する</td>
      <td><code>var(--button-radius)</code> <code>var(--table-border)</code></td>
      <td>該当コンポーネント内でのみ可</td>
    </tr>
  </tbody>
</table>

### 使い分けルール

- 色は必ずトークン参照にする。HEX リテラルをコンポーネントに直接書かない。
- 色は semantic 層以上を使う。primitive のカラースケールを直接参照するのは semantic 定義の中だけにする。
- コンポーネント固有の寸法は component 層に定義してから参照する。
- Dark Mode とポータル切替は semantic 層の再定義で吸収する。コンポーネント側に分岐を書かない。

### Tailwind v4 での注意

Tailwind v4 の任意値記法 `text-[var(--x)]` は **font-size として解釈される**ため、文字色には使えません。
色は次のいずれかで指定します。

- style prop で直接指定する: `style={{ color: 'var(--foreground)' }}`
- `@theme inline` 経由でトークンを Tailwind のカラーとして登録し、`text-foreground` のようなユーティリティで使う

背景色・ボーダー色も同様です。`bg-[var(--x)]` / `border-[var(--x)]` は解釈が曖昧になるため、
style prop か `@theme inline` 経由に統一します。

### hover / active の注意

`--hover-muted` は light では `--background-muted` と同じ `--color-gray-100` ですが、
**dark では `--color-gray-700` という別値**になります（`--background-muted` の dark 値は `--color-gray-800`）。
dark で hover が背景に埋もれないよう、意図的に 1 段明るい値を割り当てています。
hover の面には `--background-muted` ではなく必ず `--hover-muted` を使ってください。
