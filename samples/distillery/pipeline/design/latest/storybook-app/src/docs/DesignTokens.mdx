# Design Tokens

すべての実装は Primitive → Semantic → Component の3層を通して値を参照します。表示されている CSS 変数名はそのままコピーできます。

## Dark mode

`.dark` クラスと `prefers-color-scheme: dark` の両方をサポートします。ステータス背景は暗い面で発光しすぎないよう、15%透明度の `rgba()` 値へ切り替わります。
