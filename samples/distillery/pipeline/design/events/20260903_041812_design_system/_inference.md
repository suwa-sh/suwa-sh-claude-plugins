## 6. レイアウト・スペーシング推論

### 6-1. サイドバー幅
- 司書ポータルのナビ項目: 業務 5（蔵書管理 / 利用者管理 / 貸出 / 期限管理 / 運営分析）+ 共通 1（ホーム）= 6 → **コンパクト 12rem**…ただし最大ラベル「利用者管理業務」= 全角 7 文字、サブ項目「返却通知送信確認」= 全角 8 文字 → 文字切れ防止で **標準 16rem** を採用
- collapsed 幅: 4rem（アイコン 24px + 左右 padding 20px）
- 利用者ポータル: ナビ 4 項目（検索 / 貸出履歴 / 予約状況 / ログアウト）→ サイドバーなし、**トップナビ**

### 6-2. 画面パターン別カラム
| パターン | 画面 | 分割 | 根拠 |
|---|---|---|---|
| 一覧・検索 | 蔵書一覧 / 利用者一覧 / 在庫状況一覧 / 延滞・督促状況 ほか | 12col | 書籍属性 8・貸出属性 8 でテーブル必須 |
| 詳細 | 書籍詳細・在庫状況 / 書籍別予約状況 / 窓口利用状況照会 | 8col + 4col | 関連情報（予約 / 貸出）をサイドパネルに |
| フォーム | 書籍登録・編集 / 利用者登録・編集 / 予約申込 | 2 + 8 + 2 中央寄せ | フィールド数 6 / 4 ≤ 10 |
| 確認 | 削除確認 ×2 / 返却通知送信確認 / 予約取消 | 中央寄せ 6col | 確認対象 1 件 + 2 ボタン |
| 窓口 | 貸出受付 / 返却受付 | 6col + 6col | 左: 入力（利用者番号・書籍 ID）右: 判定結果 |
| 統計 | 人気書籍ランキング / 期間別貸出統計 | 4col×3 (KPI) + 12col | KPI 3（貸出件数・延滞件数・予約件数）+ チャート 1 |

### 6-3. レスポンシブ
| bp | col | サイドバー | 根拠 |
|---|---|---|---|
| lg 1024+ | 12 | 展開 | 司書 PC |
| md 768–1023 | 8 | collapsed | 利用者タブレット (F.1.1.3 Lv2) |
| sm <768 | 4 | 非表示 | スマホは要確認 → 簡易対応 |

### 6-4. スペーシング
| トークン | 値 | 根拠 |
|---|---|---|
| page-padding | 1.5rem (6) | サイドバーあり管理画面が主体。表示領域を優先 |
| section-gap | 2rem (8) | 情報.tsv 属性数平均 6.3（書籍 10 / 利用者 6 / 貸出 8 / 予約 6 / 通知 11 / 統計 8 / ジャンル 3 / 期間 3 / リマインド 3）→ 高密度 |
| component-gap | 0.75rem (3) | 標準。フォーム・リスト |
| card-padding | 1.5rem (6) | カード候補（書籍）の属性数 ≥ 5 |
| 適用原則 | gap > padding > margin | margin は section-gap のみに限定 |
