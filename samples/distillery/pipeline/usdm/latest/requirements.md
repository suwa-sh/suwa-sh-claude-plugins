| ID | 要求 | 仕様 | 理由（背景） | 説明 |
|----|------|------|------------|------|
| REQ-001 | 図書館の蔵書と利用者を一元管理できるようにする | | 蔵書と利用者の情報が紙台帳と表計算ファイルに分散しており、司書の管理の手間と転記ミスが発生しているため。単一の正となるデータを持つことで管理コストとミスを削減する | |
| SPEC-001-01 | | 司書は書籍情報（タイトル、著者、ISBN、出版社、ジャンル）を登録・編集・削除できる | | 1. Given 司書がログイン済み When 書籍情報（タイトル、著者、ISBN、出版社、ジャンル）を入力して登録する Then 蔵書として保存され一覧に表示される<br>2. Given 登録済みの書籍 When 司書が書籍情報を編集して保存する Then 変更内容が反映される<br>3. Given 貸出中でも予約待ちでもない書籍 When 司書が削除する Then 蔵書から除外される |
| SPEC-001-02 | | 司書は利用者情報（氏名、連絡先、利用者番号）を登録・編集・削除できる | | 1. Given 司書がログイン済み When 氏名・連絡先を入力して利用者を登録する Then 利用者番号が採番され利用者として保存される<br>2. Given 登録済みの利用者 When 司書が利用者情報を編集して保存する Then 変更内容が反映される<br>3. Given 貸出中・予約中のない利用者 When 司書が削除する Then 利用者一覧から除外される |
| SPEC-001-03 | | 利用者と司書は書籍をキーワード、タイトル、著者、ISBN、ジャンルで検索できる | | 1. Given 蔵書が登録済み When キーワード・タイトル・著者・ISBN・ジャンルのいずれかで検索する Then 条件に一致する書籍の一覧が表示される<br>2. Given 検索結果の一覧 When 書籍を選択する Then 書籍情報と在庫状況（在庫あり／貸出中／予約待ち）が表示される |
| REQ-002 | 書籍の貸出・返却・予約を Web 画面から行えるようにする | | 貸出・返却・予約の管理を司書が手作業で行っており、手間とミスの原因になっているため。Web 化により処理を標準化し利用者サービスを向上させる | |
| SPEC-002-01 | | 司書は在庫のある書籍を利用者へ貸し出し、貸出記録を作成する | | 1. Given 在庫ありの書籍と有効な利用者 When 司書が貸出を実行する Then 貸出記録が作成され書籍の状態が貸出中になる<br>2. Given 貸出中の書籍 When 司書が同じ書籍の貸出を実行する Then 貸出できない旨のエラーが表示される |
| SPEC-002-02 | | 司書は貸出中の書籍の返却を受け付け、貸出記録を返却済みにする | | 1. Given 貸出中の書籍 When 司書が返却を受け付ける Then 貸出記録が返却済みになり返却日が記録される<br>2. Given 予約のない書籍が返却された When 返却処理が完了する Then 書籍の状態が在庫ありになる |
| SPEC-002-03 | | 利用者は貸出中の書籍に予約でき、予約は申込順に順位付けされる | | 1. Given 貸出中の書籍 When 利用者が予約を申し込む Then 予約が申込順の順位付きで登録される<br>2. Given 在庫ありの書籍 When 利用者が予約を申し込む Then 予約できない旨が案内される<br>3. Given 同一書籍に自分の有効な予約がある When 再度予約を申し込む Then 重複予約できない旨が案内される |
| SPEC-002-04 | | 書籍が返却されたら予約順1位の利用者へ取置き可能となった旨をメールで通知する | | 1. Given 予約のある書籍が返却された When 返却処理が完了する Then 予約順1位の利用者へメール通知が送信され書籍の状態が予約待ちになる<br>2. Given 通知対象の予約 When 通知が送信される Then 予約状態が取置き中に更新される |
| REQ-003 | 貸出期限の管理と延滞者への通知を自動化する | | 期限管理と督促を司書が手作業で行うと漏れやすく負荷が高いため。自動化により延滞を減らし司書の作業を削減する | |
| SPEC-003-01 | | 貸出時に貸出日を起点とした返却期限を自動設定する | | 1. Given 貸出処理を実行する When 貸出記録が作成される Then 貸出日を起点とした返却期限が自動で設定される<br>2. Given 返却期限が設定された貸出 When 貸出情報を参照する Then 返却期限が表示される |
| SPEC-003-02 | | 返却期限が近づいた貸出について利用者へリマインドメールを自動送信する | | 1. Given 返却期限が近い貸出中の書籍 When リマインド対象の判定が実行される Then 対象利用者へリマインドメールが自動送信される<br>2. Given 既に返却済みの貸出 When リマインド対象の判定が実行される Then リマインドメールは送信されない |
| SPEC-003-03 | | 返却期限を超過した貸出について利用者へ督促メールを自動送信し、延滞として管理する | | 1. Given 返却期限を超過した貸出中の書籍 When 督促対象の判定が実行される Then 対象利用者へ督促メールが自動送信され貸出状態が延滞になる<br>2. Given 延滞中の貸出 When 書籍が返却される Then 貸出状態が返却済みになり督促が停止する |
| REQ-004 | 利用者が自分の貸出履歴と予約状況を Web 画面で確認できるようにする | | 利用者が自分の利用状況を司書に問い合わせずに把握できるようにして、利用者サービスを向上させ司書の問い合わせ対応を減らすため | |
| SPEC-004-01 | | 利用者は自分の現在の貸出と過去の貸出履歴を Web 画面で照会できる | | 1. Given 利用者がログイン済み When 貸出履歴画面を開く Then 現在借りている書籍と過去に借りた書籍の一覧が表示される<br>2. Given 現在の貸出がある When 貸出履歴画面を開く Then 各貸出の返却期限が表示される<br>3. Given 他の利用者の貸出 When 自分の貸出履歴画面を開く Then 他の利用者の貸出は表示されない |
| SPEC-004-02 | | 利用者は自分の予約状況（予約順位・取置き状況）を Web 画面で照会できる | | 1. Given 利用者が予約中の書籍がある When 予約状況画面を開く Then 予約中の書籍と自分の予約順位が表示される<br>2. Given 取置き中の予約がある When 予約状況画面を開く Then 取置き中である旨が表示される |
| REQ-005 | 司書が在庫状況・人気書籍ランキング・期間別貸出統計をレポートとして把握できるようにする | | 蔵書の稼働状況を定量的に把握して、選書・購入判断や運用改善に活かすため。現状は表計算ファイルの集計に手間がかかっている | |
| SPEC-005-01 | | 司書は蔵書の在庫状況（貸出中・在庫あり・予約待ち）を一覧レポートとして参照できる | | 1. Given 蔵書と貸出・予約が登録済み When 司書が在庫状況レポートを開く Then 貸出中・在庫あり・予約待ちの区分ごとに件数と書籍一覧が表示される |
| SPEC-005-02 | | 司書は貸出実績に基づく人気書籍ランキングと期間別の貸出統計を参照できる | | 1. Given 貸出実績が蓄積されている When 司書が期間を指定してレポートを開く Then 期間内の貸出件数と貸出回数上位の書籍ランキングが表示される<br>2. Given 貸出実績が存在しない期間 When レポートを開く Then 実績なしである旨が表示される |
| REQ-006 | 将来的に電子書籍を扱えるように蔵書の資料種別を拡張可能にしておく | | 現時点では紙の書籍のみを対象とするが、将来の電子書籍対応時にモデルの作り直しを避けるため | |
| SPEC-006-01 | | 蔵書を資料種別（紙書籍／電子書籍）で区別できるモデルとし、初期リリースでは紙書籍のみを有効とする | | 1. Given 書籍を登録する When 資料種別を指定する Then 紙書籍として登録され資料種別が保持される<br>2. Given 電子書籍の資料種別 When 初期リリースで選択する Then 未対応である旨が案内され登録されない |
