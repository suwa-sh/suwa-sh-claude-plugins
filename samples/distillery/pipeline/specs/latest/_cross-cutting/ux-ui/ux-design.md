# 画面間の接続

利用者は蔵書を探して予約し、自分の貸出と予約を確認する。
司書は蔵書と利用者を管理し、窓口で貸出と返却を記録する。

| 操作 | 次の画面 | 受け渡す値 |
|---|---|---|
| 検索結果を選択 | 書籍詳細 | 選択した書籍ID |
| 書籍詳細から予約 | 予約申込 | routeの書籍ID |
| 自分の予約を取消 | 予約取消 | 選択した予約ID |
| 司書が利用者を選択 | 窓口利用状況照会 | 選択した利用者番号 |
| 司書が書籍の予約一覧を選択 | 書籍別予約状況 | 選択した書籍ID |
| 返却後に通知結果を確認 | 返却通知送信確認 | 返却結果の貸出ID |

画面名とrouteは[ScreenMapping](../../../../design/latest/storybook-app/src/docs/ScreenMapping.mdx)を参照する。
各routeの直リンクではrouteパラメータからAPIを再取得する。
一覧へ戻るときは検索条件とページ番号をURLから復元する。
